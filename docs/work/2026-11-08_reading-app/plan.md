# 計画:読み物中心への作り替え+dialogues の追加(2026-11-08 承認)

種類:新規作成
目的:「チャットで教えてもらった解説を、チャットを遡らずに教科書のように読み返す」アプリにする。問題は読んだ後の確認用の付録。

## 1. 要件

### 画面(下のタブ:ホーム/セッション/検索/しおり/演習)

1. ホーム:「続きから読む」「最近追加されたセッション」、分野 → 大分類 → トピックの目次(既読に ✓)
2. トピック画面の表示順:たとえ → 要約(+要点)→ 図 → 解説(+公式)→ チャットでのやりとり → あなたのつまずき → 用語 → 関連トピック(+前提トピック・比較カード)→ 確認問題(折りたたみ、その場で解ける)
3. 読みやすさ:本文 17px 程度、行間を広く、冒頭に「このページの目次」(押すとその見出しへ移動)
4. やりとりはチャット風(質問は短く右寄せ、解説は全幅)。表は表の中だけ横スクロール。dialogues がないトピックではセクションを出さない
5. セッション画面:一覧(日付順)→ 詳細(元のチャットへのリンク、そのセッションのトピック、やりとりを日付順)
6. 全文検索:トピック名・要約・解説・やりとり・用語。一致箇所と前後の文を表示し、押すと該当セクションへ。全角半角・大文字小文字を区別しない
7. しおり(☆)と既読(「読み終えた」)。localStorage に保存し、トピック id で紐づける。しおりタブで一覧
8. 演習タブ:今の演習を移す。今日の復習・弱点表示は次の段階でここに作る

### 教材データの拡張

- トピックに任意の配列フィールド `dialogues`:`{ sourceKey, date, title, turns: [{ role: "user"|"assistant", text }] }`
- `tools/content-lib.mjs`:dialogues を追記対象の配列フィールドに。重複判定は sourceKey + title
- `tools/validate.mjs`:sourceKey がパックの sources にあるか、role が user/assistant か、title・turns があるか、text が空でないか(エラー)。date の形式違いは警告
- `src/content/merge.ts` も同じルールにし、テストで一致を確認
- `content/SCHEMA.md`、`docs/SPEC.md`、`docs/ADDING_CONTENT.md` を更新

### 公開と個人情報(公開リポジトリのまま)

- `CLAUDE.md`、`docs/SPEC.md` の利用者の名前を「利用者」に置き換える
- `docs/ADDING_CONTENT.md` の依頼文に「dialogues に個人的な内容を入れない」を追加
- 承認時の追加指示:今後セッションを追加するときは、個人情報が入っていないか確認してから追加する
  - `CLAUDE.md` の「新しい教材パックが追加されたとき」に個人情報の確認手順を追加
  - `tools/validate.mjs`:メールアドレス・電話番号・郵便番号の形の文字があれば警告。PC だけに置く `content/private-words.txt`(.gitignore 対象)の言葉が見つかればエラー

## 2. 技術

- mermaid(新規追加。図がある画面でだけ遅延読み込み)
- localStorage(しおり・既読・続きから読む)
- 検索は自作(NFKC 正規化+部分一致)

## 3. 影響範囲

- 演習画面:回答部分を確認問題と共通の部品に切り出す(動きは同じ)
- 出題の選び方の画面:演習タブへ移す
- `tools/`:機能追加のみ。今の6パックは「エラーなし・55トピック・108問」のまま
- `content/packs/`:変更しない

## 4. 実装計画

1. この plan.md
2. 名前の置き換え
3. dialogues の統合・検査・個人情報チェック、型、テスト
4. 目次・セッションの並び、検索、しおり・既読の保存とテスト
5. 部品:図、やりとり、回答部分
6. 画面:ホーム、トピック、セッション一覧・詳細、検索、しおり、演習タブ
7. タブと読みやすい見た目
8. 文書の更新(SCHEMA、SPEC、ADDING_CONTENT、CLAUDE.md)
9. 検証役 → 公開 → スクリーンショットと URL で報告

## 5. 確認方法

- `npm test`:dialogues 入りの人工データで TS 版と content-lib.mjs が一致。同じ sourceKey + title は重複しない
- `node tools/validate.mjs`:今の教材はエラーなし(55トピック・108問)
- 一時的に「role が間違い」「sourceKey が未定義」のパックを置くとビルドが止まる(確認後すぐ削除)
- 一時的に dialogues 入りのテスト用パックを置き、幅360pxで質問は右寄せ・解説は全幅・表ははみ出さない(確認後すぐ削除、コミットしない)
- 今の教材のトピックでは、やりとりのセクションが出ない
- 検索:「XOR」と「ｘｏｒ」で同じ結果。結果を押すと該当セクションへ
- しおり・既読:再読み込みしても残る。ホームの目次に ✓
- 演習タブのランダム10問が前回と同じ手順で動く
- リポジトリ全体を利用者の名前で検索して見つからない(履歴を除く)
- private-words.txt の言葉を含む一時パックで検査がエラーになる(確認後すぐ削除)
- push 後に自動公開が成功し、スマホ幅のスクリーンショットと URL を渡す

## 仮定

- 要点は要約の直後、公式は解説の直後、前提トピックと比較カードは関連トピックの場所
- dialogues の中身はチャット側で作る
- PC の2列表示は今回は入れない
- 過去の git 履歴に名前は残る(履歴の書き換えはしない)
