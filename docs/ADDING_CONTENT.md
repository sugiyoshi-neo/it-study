# 新しいセッションを教材に追加する手順

Claude Code はチャットの履歴を読めないため、**教材づくりはチャット、アプリへの反映は Claude Code** と分担します。

```
① チャットで勉強する(いつも通り)
        ↓
② チャットに「教材パックを作って」と頼む  … 新しいパック(JSON)ができる
        ↓
③ パックをこのリポジトリの content/packs/ に置く
        ↓
④ Claude Code に「検査してデプロイして」と頼む  … アプリに反映
```

---

## ② チャットへの頼み方

claude.ai の新しいチャットで、次の2つのファイルを添付して、下の依頼文を送ります。

- `content/SCHEMA.md`(教材データの形式)
- `content/topic-index.md`(今あるトピックの一覧。`node tools/validate.mjs --index` で最新にしておく)

### 依頼文(コピーして使う)

```
IT学習アプリの教材パックを作ってください。

【対象セッション】
・(セッション名1)
・(セッション名2)

【手順】
1. 対象セッションを過去のチャットから探して、全文を読む
2. 私がつまずいた箇所を分析する(問題文が読めない/記号が読めない/前提知識がない/なぜが分からない/似た概念の混同/ひっかけ/計算/トレース)
3. 添付の SCHEMA.md の形式で、教材パック(JSON)を1つ作る
   - 添付の topic-index.md に同じ内容のトピックがあれば、新規ではなく同じ id で追記する
   - 問題 id は topic-index.md の使用済みと重ならないようにする
   - 私が間違えた問題は missedInSession: true にする
   - 誤答の選択肢には wrongReasons を付ける
   - 問題文が読みにくい問題には readingAid を付ける
   - 私がつまずいた点は pitfalls に書く
   - 解いた問題は origin: "session-reconstructed"、理解確認用に作った問題は "original"
4. JSON として正しいか、正解が選択肢にあるか、計算が合っているかを確認してから、ファイルで渡す
5. 最後に、今回のつまずき分析を3〜5行で教えて
```

### 定期的に追加する場合

週1回など決まったペースで追加したいときは、上の依頼文をチャットのスケジュール機能(scheduled task)に登録することもできます。その場合は、対象セッションを「直近1週間で、タイトルに『基本情報』『IT』を含むチャット」のように、自動で判別できる条件にしてください。

---

## ③ パックを置く

チャットから受け取った JSON を `content/packs/` に保存します。ファイル名はチャットが付けたもの(`YYYY-MM-DD_連番_内容.json`)のままにします。**ファイル名順に統合されるので、日付が新しいものほど後に読み込まれます。**

---

## ④ Claude Code への頼み方

```
content/packs/ に新しい教材パックを追加しました。検査して、問題なければコミットしてデプロイしてください。
```

Claude Code は次のことを行います。
1. `node tools/validate.mjs --index` で検査し、`topic-index.md` を更新
2. エラーがあれば内容を報告する(教材の中身は勝手に書き換えない。形式エラーの直し方を提案する)
3. 問題なければ、ビルド・コミット・プッシュ → 自動デプロイ
4. 追加されたトピック数・問題数を報告する

---

## よくある検査エラーと対処

| エラー | 原因 | 対処 |
|---|---|---|
| 問題 id が重複 | 既存の問題と同じ id | チャットに「q-xxx-1 が重複しているので id を変えて」と頼む |
| 前提トピック "xxx" が存在しません | 存在しない id を前提にしている | topic-index.md を添付し直して作り直してもらう |
| answer が選択肢にありません | 正解の id の書き間違い | チャットに直してもらう |
| field が不正 | 4つの分野以外 | テクノロジ系 / マネジメント系 / ストラテジ系 / 実務・IT用語 のいずれかに |
