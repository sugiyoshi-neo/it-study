# パターン集（過去の修正と学び）

作業のたびに Claude が追記し、次回以降の判断材料にするファイル。
調査の最初に必ず読む。

## 書き方

1つの学びにつき、以下の形で1項目を書く。
同じ種類の学びがすでにある場合は、新しく足さずに既存の項目を更新する。

```
### 見出し（何についての学びか一言で）
- 日付：YYYY-MM-DD
- 種類：バグ修正 / 新規作成
- 症状・状況：何が起きたか、何を作ったか
- 原因・判断：なぜ起きたか、なぜその作り方にしたか
- 対処：どう直したか、どう作ったか
- 次回の注意：次に似た作業をするときに気をつけること
- 関連ファイル：
```
